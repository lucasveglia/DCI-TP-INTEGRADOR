## Propuesta ##
Se buscó diseñar el PCB para un sintetizador musical a partir del integrado ICL8038. Para esto se partió de un modulo comercial de un generador de funciones a partir del ICL8038. Las imagenes del PCB y esquemáticos se consiguieron de la guía de ensamblaje y análisis realizado por  Jos Verstraten (pdf adjunto).
Las modificaciones realizadas fueron:
- Quitar el potenciometro de selección de frecuencia fija para reemplazarlo por un pin de entrada (al que se lo reemplazaría por pulsadores y resistencias que generen distintas frecuencias, a modo de teclado. Esto iría por fuera y no se implementaría en este proyecto).
- Quitar los capacitores de selector de rango de frecuencia y dejar solo uno fijo correspondiente al rango de 500Hz a 20KHz.
- Renumerar algunos componentes para compensar los elementos removidos.
